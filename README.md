Linux Administration Portfolio
This is where I keep my lab work from CIS-245 Linux Administration.

The labs below show what I have been working on this term: setting up Linux servers, using shell tools for text processing, managing packages and services, and documenting everything along the way.

Labs
Server Setup
Setting up CentOS Stream 10 and Ubuntu 26.04 in VirtualBox, troubleshooting network problems (Bridged vs NAT), and getting file transfers working with scp and port forwarding.

Grep Lab
Searching files for patterns using grep and regular expressions. Covered anchors, character classes, alternation, and inverted matches.

Sed Lab
Stream editing with sed. Substitution, deletion, line ranges, pattern addresses, and writing a sed script.

Awk Lab
Field-based text processing with awk. Printing specific fields, filtering by conditions, doing arithmetic on fields, and writing an awk script.

Installs Lab
Package installation on CentOS and Ubuntu. Covered EPEL setup, fail2ban configuration, and full documentation of what was installed and when.

Networking Lab 
(networking/networking-lab.md)

Network configuration for both servers, plus two scripts. One dumps network info to a file. The other is interactive and gives troubleshooting steps based on which server you are on.

IPTables Lab
Firewall configuration and DDoS testing on both servers. Covered port forwarding, allowing specific services, blocking insecure protocols, and implementing connection limits.

Installs, Updates, and Documentation Lab
Package installation on CentOS and Ubuntu. Covered EPEL setup, fail2ban configuration, testing each program, and full documentation of what was installed and when.
